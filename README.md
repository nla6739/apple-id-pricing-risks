## 常见问题

**能登 iCloud 吗？**
未激活版只能登 App Store，登不了设置里的 Apple ID 入口。已激活版可以登，但建议登录后立刻关闭“查找我的 iPhone”。如果 App Store 能登、iCloud 登不上，先分清两种提示：“需要验证”通常是流程没走完，比如邮箱或手机号没验证、条款没同意；“已被锁定”是苹果主动切断访问，改密也进不去，这种情况直接联系售后。

**能一直用吗？**
没有永久承诺。苹果可能因异常登录、关联设备过多收回或停用，平台不承担找回责任。保持活跃、定期改密、只登 App Store、不借他人、单设备使用，能把概率压低。

**能当游戏账号或充值账号吗？**
官方明确禁止。账号只用于下载海外游戏软件，别拿它登录游戏存档、别往里充钱买内购。要买付费应用就用礼品卡给 ID 充余额。

**批量买有折扣吗？**
有议价空间。平台商品说明写的是“若需要大量批发可以联系我们的线上客服，客服会安排转人给您联系详谈价格”。具体折扣阶梯没有官方公开，需要向客服确认。第一次合作建议先买 5–10 个试稳定性、发货速度和售后响应，再决定加量。

**号被封了怎么办？**
